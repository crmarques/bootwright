The `missing-gplv3-license` exceptions apply only to internal documentation
stubs paired with controller action plugins, to the adapter's output callback,
which extends ansible-core's default, to the `ssh_key_policy` and `private_file`
modules that run on the placement host, and to the `managedos_registration` and
`containercluster_install_placement` modules that run on the controller. This repository has no GPL grant; the exceptions
preserve the existing licensing status and do not grant a license or bypass
capability validation. All other sanity checks still apply.

# M7 — Standalone native input files and commands

Generate native input files for `openshift-install` and for the cephadm and
ceph CLIs: rendered, disposable artifacts an operator runs outside any
Bootwright operation. The
[extension model](../project.md#implementation-and-extension-model) lists
native files, scripts and inventories among Bootwright's generated outputs.
Independent execution of these artifacts creates no Bootwright operation,
lease, ownership or continuation state; only [B60](#b60) publishes as an owned
effect.

**Requires:** M4, so standalone rendering is the final milestone (M6 retired under D173); [legacy M1b](delivered.md#m1b--durable-contexts-and-desired-state-admission), [legacy M1c](delivered.md#m1c--context-secret-management)
and [legacy M1e](delivered.md#m1e--lifecycle-engine-and-managed-artifact-serving) are delivered. Its OpenShift and Ceph projections reuse M3 and M2's
qualified lifecycle inputs. **Exit tier:** in-tree
(goldens, no execution). **Open decisions:** none numbered; each item but
[B1033](#b1033) needs definition.

## Item detail

### B51

Define the typed manifest, canonical bytes, destinations and overwrite rules
of rendered native files, the contract [B52](#b52) and [B55](#b55) share. **Exit evidence:** manifest and overwrite tests, and
metadata goldens.

### B52

Make the [installer inputs](../openshift-clusters.md#installer-inputs) an
operator-run standalone artifact through `render installer`, with the secret
placeholders and optional sensitive render that command owns. The projection
itself is delivered in code by [B61](m3.md#b61), which freezes it in a plan
instead of writing it to a chosen directory. Map identity, roles, networks,
VIPs, hosts, interfaces, root hints and rendezvous. **Exit evidence:** proof of
API sufficiency, sensitive publication and cleanup, non-disclosure and
release-specific native goldens. A FIPS slice also qualifies the matching
installer and artifact parity.

### B53

Validate NMState and installer schema parity for the rendered inputs of
[B52](#b52). **Exit evidence:** parity tests against the qualified release's
schemas.

### B54

Validate and bind the pull secret and public SSH key the rendered inputs of
[B52](#b52) carry. **Exit evidence:** binding and non-disclosure tests.

### B55

Render typed storage intent into one release-specific declarative file set for
cephadm and the ceph CLI, reusing [B472](m2.md#b472)'s qualified managed
projection. Qualify standalone publication against the
[storage field records](../api/ceph.md#kinds) and reject unprovable
fields; revise the API deliberately if needed. **Exit evidence:** native
goldens and negative disclosure tests.

### B56

Reuse [B472](m2.md#b472)'s storage secret consumer validation and immutable
binding, and define standalone sensitive publication for [B55](#b55)'s file set, or prove its outputs
secret-free. **Exit evidence:** binding and non-disclosure tests.

### B57

Generate one deterministic native-CLI Ceph pool script. No authored shell
fragments, inline secrets or execution. **Exit evidence:** argument encoding,
replay semantics, diagnostics, sensitive classification, publication and
goldens.

### B58

Define the pool script's manifest, bytes, fixed command structure, destination
and generation journey. **Exit evidence:** manifest goldens.

### B59

One local bootable installer ISO an operator builds and keeps, outside any
operation. The image a cluster installs from is delivered in code by
[B61](m3.md#b61) as an owned lifecycle effect, published privately and removed
by its inverse; what remains here is a disposable artifact with no operation,
no ownership and no remote publication. **Exit evidence:** an exact builder and
its dependencies, bounded inputs, sensitive classification, a typed manifest
and digest, atomic publication, metadata goldens, negative effect tests and
boot evidence.

### B60

Publish rendered native artifacts into a managed `ArtifactServer`'s served root
as an owned lifecycle effect, with typed content manifests and digests.
Consumer publication beneath the served root is delivered in code by
[B72](delivered.md#x38--the-real-host-run-of-2026-10-05), whose installer ISO and package tree are the first content
producer; rendered boot artifacts arrive with [B59](#b59) and [B52](#b52). A
frozen plan cannot be appended; publication is a block of its own operation.
**Exit evidence:** a typed content manifest and digests, destination and
overwrite rules within the owned root, atomic publication, retention through
destroy, bounded source reads, sensitive classification and negative effect
tests.

### B320

`internal/containercluster/installation` holds the `render installer` stub,
while `managedos/installation` and `containercluster/agentinstall` are
installations, so its name misleads a reader (found by the 2026-10-05 audit).
It is renamed for rendering, with the layout and boundary tests, or
[B52](#b52) renames it when it implements the command. **Exit evidence:** the
layout and boundary tests over the new name.

### B1033

Make the lifecycle's decision and its execution meet at one named value. The
private `transition` becomes an `operationPlan` in its own file: the frozen
block DAG with the bound selection, the decided mode, the durable basis the
executor re-proves, the capability bindings and the removal phases. The
removal phases, which the executor recomputes at nine sites today, are
computed once per decision and passed to the scheduler, the attempts and the
gates. `execution.go` is split by concern into planner and executor files,
which adopts parked [B328](backlog.md#b328), and a fitness test holds the
partition: planner code reaches no effect and executor code never plans
again. Contract: [state reconciliation](../state-reconciliation.md#plan-and-execution)
changes only by its one paragraph on the operation plan; no plan, digest,
operation record or command output changes. [B1034](#b1034) is the later
consumer this prepares; exporting the value waits for it.
**Exit evidence:** the partition tests
`TestLifecyclePlannerReachesNoEffect`, `TestLifecycleExecutorNeverReplans` and
`TestLifecycleFilesAreClassified` (`test/architecture/lifecycle_partition_test.go`),
`TestOperationPlanHoldsNoHandles` (`internal/reconciliation/lifecycle/operation_plan_test.go`),
`TestPhasesMatchRecomputation` (`internal/reconciliation/lifecycle/phases_test.go`),
which holds the decided removal phases equal to their recomputation over every
destroy fixture, every plan, operation and CLI golden byte-identical,
`make check` and `make race`.

### B1034

Generate, from one operation plan and into a directory the operator names, a
markdown main page and chapters that give every step the plan performs
command by command with native tools only, with the native input files beside
them, so an operator can audit the procedure or follow it when Bootwright is
unavailable. Creates no operation, lease or ownership. The design is the
[native procedure](../deferred/native-procedure.md) page, which waits for the
native-file items [B51](#b51) and its successors. **Exit evidence:** to define
at promotion: the port, the output layout and golden procedures per
implementation.

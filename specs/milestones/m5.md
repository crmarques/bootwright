# M5 — First add-ons

The first add-ons: ingress through MetalLB, and the integration of OpenShift
with a Ceph cluster through IBM Fusion Data Foundation. The
[product scope](../project.md#product-scope) names both packages among the
cluster-bound integrations. The Ceph side is a cluster M4 manages (D19); an
external Ceph cluster is parked as [B107](backlog.md#b107). An example package
already exists at
[`examples/multidc-platform/add-ons/fusion-data-foundation`](../../examples/multidc-platform/add-ons/fusion-data-foundation/add-on.yaml).

**Requires:** M3, for a supported cluster, and M4, for the Ceph cluster.
**Exit tier:** an emulated rehearsal until B83's definition fixes it. **Open
decisions:** none numbered.

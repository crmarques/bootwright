# Bare-Metal Redfish Fleet With Imported Ceph Data Foundation

This example installs two OpenShift clusters and binds both to a previously
provisioned Ceph cluster through OpenShift Data Foundation external mode.
Bootwright does not run `cephadm` or create Ceph pools/users for
`StorageCluster/shared-ceph`; it reads the Ceph external cluster details JSON
from `Environment.spec.secrets.shared-ceph-external-details`.

Expected flow:

```text
bootwright check syntax -f examples/baremetal-redfish-fleet-imported-ceph-data-foundation
bootwright context init imported-ceph -f examples/baremetal-redfish-fleet-imported-ceph-data-foundation
bootwright secret set shared-ceph-external-details --raw-file <external-details.json>
bootwright secret generate
bootwright apply all --yes
```

`external-details.json` should contain the raw JSON array generated by
`ceph-external-cluster-details-exporter.py`. Keep it outside versioned content;
Bootwright stores it as the context-local `shared-ceph-external-details`
secret and renders the Data Foundation binding manifests from
`StorageClusterBinding/shared-ceph-data-foundation`.
